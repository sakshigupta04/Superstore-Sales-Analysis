# Superstore Sales Analysis

## Project Overview
This project analyzes Superstore sales data to understand business performance and sales trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Data Cleaning
2. Monthly Sales Analysis
3. Category-wise Revenue Analysis
4. Discount vs Profit Analysis
5. Region-wise Sales Analysis

## Objective
To identify sales trends, understand product category performance, and provide useful business insights.

## Files
- Superstore_Analysis.ipynb – Complete analysis notebook.
- superstore_sales (1).csv – Dataset.
